# 24x7 News Time — 24x7newstime.in

Hindi news portal on GitHub Pages.

- `index.html` + `assets/site.js` render the news from `data/news.json`.
- `data/news.json` is rewritten every 30 minutes by the n8n workflow **"24x7 News Time - Auto Update"** (39 Hindi publisher RSS feeds). Do not edit it by hand.
- Headlines always link to the original publisher; full articles are never copied.
- Logo files: `assets/logo-mark.webp` (header), `assets/icon.png` (favicon, app icon, share image).
